# Security

정보보안기사 준비와 보안 기초 학습 내용을 정리합니다.

## 구성

- `Basics/` : 보안의 기본 개념
- `Network/` : 네트워크 보안
- `System/` : 시스템 보안
- `Web/` : 웹/애플리케이션 보안
- `Crypto/` : 암호학
- `Management-Law/` : 정보보안 관리 및 법규
- `Exam/` : 정보보안기사 시험 대비 및 오답 정리

## 정리 원칙

각 문서는 가능한 한 아래 순서로 정리합니다.

1. 한 줄 요약
2. 왜 필요한가
3. 핵심 개념 / 동작 원리
4. 시험 포인트
5. 헷갈리기 쉬운 부분
6. 실무 연결

완벽하게 정리하는 것보다, 공부하면서 이해한 내용을 계속 보완하는 것을 우선합니다.
